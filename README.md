# IoT Edge-Network Queueing Models — Course Materials

Supporting specifications for a Probability & Statistics course project on queueing and edge-computing networks, Sharif University of Technology. **Course instructor:** Dr. Mohammad Mehdi Mojahedian.

**Archive status:** only the two assignment PDFs were recovered in the current upload. The student's solution report, analysis, simulation code, and results are not included. This repository is a clearly labelled materials archive, not a runnable implementation or a set of completed results.

| Material | Scope |
| --- | --- |
| [Phase 1](docs/assignment/PS-Project_Phase1.pdf) | Queueing concepts, stochastic modeling, and theoretical questions |
| [Phase 2](docs/assignment/PS-Project_Phase2.pdf) | Edge, collecting, and main servers; finite queues, feedback, throughput, and cost tradeoffs |

The assignment documents retain their original instructor/designer attribution. Their authorship is not claimed by the repository owner. Implementation and results can be added when the original solution files are recovered; they should be kept separate from `docs/assignment/`.
